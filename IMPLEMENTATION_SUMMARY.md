## 🚀 How to Run

### Quick Start (Recommended)

```bash
# Make sure .env file exists with GOOGLE_API_KEY
./start.sh
```

### Manual Start

**Terminal 1 - Backend**:

```bash
cd api
uv venv
source .venv/bin/activate
uv pip install -r requirements.txt
uv run uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

**Terminal 2 - Frontend**:

```bash
cd ui
npm install
npm run dev
```

## 🌐 Access Points
